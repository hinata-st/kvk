# 纯前端本地应用，不建后端

使用者只有作者本人，且原始数据（KovaaK's 写出的逐局 stats CSV）本来就躺在本地磁盘上。因此不做服务端：没有数据库、没有账号、没有云同步。解析、聚合、持久化全部在浏览器内完成，目录句柄与解析结果存 IndexedDB。

## Considered Options

- **本地 Node 服务 + SQLite** — 可以做后台定时扫描和重计算，但需要额外安装、开机自启、端口管理，对单人自用是纯负担。
- **云端后端 + 账号** — 换来多设备同步与分享能力，但引入隐私、成本与运维，而本项目明确不需要分享。

## Consequences

- 换电脑或换浏览器会丢数据，需要重新选一次 stats 目录重建索引。
- 结果无法直接分享给别人看。
- 重计算（比如切换灵敏度分组、重算段位）只能在前端做，需要为此留意性能。
